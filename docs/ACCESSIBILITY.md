# Accessibility baseline

OpenScroll targets WCAG 2.2 AA.

Epic A provides:

- Semantic landmarks and labeled navigation
- Visible keyboard focus and logical source order
- 44 × 44 px minimum interactive targets
- Native modal focus management and Escape behavior
- Accessible names and tooltips for icon-only controls
- Reduced-motion and forced-colors support
- Responsive mobile, tablet, and desktop shells
- LTR and RTL layout behavior
- Automated axe-core checks at desktop and mobile viewports

Automated checks do not replace manual testing. Each product epic must also test keyboard-only navigation, VoiceOver, TalkBack, NVDA, zoom at 200% and 400%, reduced motion, high contrast, and text reflow.
